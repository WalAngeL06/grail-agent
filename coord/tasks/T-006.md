# T-006 · Otonom agent döngüsü (T-001, T-002, T-003 entegre olduktan sonra)
- Sahip: agents (Codex · hesap 1) · worktree `Agentic Hack-wt/agents` · branch `role/agents`
- Amaç: Puanın %35'i otonomi. Döngü insan onayı olmadan çalışır, guardrail'lerle.

## Döngü (her `cycle_seconds`'ta)
1. Config'i doğrula (engine.validate_config). Geçersizse başlama.
2. ATK'dan snapshot al.
3. engine.decide → coin başına karar (HOLD dahil).
4. Kanonik payload + rastgele salt → commitHash → `commitDecision` tx. Başarısızsa: emir YOK, logla, sonraki döngü.
5. BUY/SELL ise guardrail kontrolü (coin listesi, emir başı ve toplam limit, kill switch); geçerse `dry_run` false ise ATK canlı spot emri, true ise simüle emir (`order_status: "simulated"`); emir durumunu sorgula.
6. `revealDecision(payload, salt, okxOrderId)` tx.
7. `runtime/state.json` yaz (`contracts/state.example.json` biçiminde).
8. Herhangi bir adımda hata → `state.errors`'a ekle, döngü devam eder (agent durmaz).

## Kabul
- 14:00 kapısı: 1 commit tx + 1 emir (önce dry_run, kullanıcı açınca küçük canlı) + 1 reveal tx; kimlikler `coord/STATE.md`'ye (integrator yazar).
- `agents` içindeki hash fonksiyonu `contracts/chain.json` → `testVector` ile aynı sonucu verir (test).
- Sunum ayarı: `cycle_seconds` 60–120; her döngüde zincirde aktivite (HOLD dahil).
