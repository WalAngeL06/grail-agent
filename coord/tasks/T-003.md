## Kapsam (Hardhat + TypeScript, `chain/` altında)
- `registerAgent(string name)` → agentId; event `AgentRegistered`.
- `commitDecision(uint256 cycleId, bytes32 commitHash)`; event `DecisionCommitted(agentId, cycleId, commitHash, blockTime)`.
- `revealDecision(uint256 cycleId, bytes payload, bytes32 salt, string okxOrderId)`:
  `keccak256(abi.encodePacked(payload, salt)) == commitHash` değilse revert. okxOrderId hash'e girmez. Event `DecisionRevealed(agentId, cycleId, payload, okxOrderId)`.
- Aynı (agentId, cycleId) için ikinci commit/reveal revert. Commit edilmemiş reveal revert.
