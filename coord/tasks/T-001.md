# T-001 · Quant engine çekirdeği + golden testler
- Sahip: engine (Claude Code · Max) · worktree `Agentic Hack-wt/engine` · branch `role/engine` · contracts 0.3
- Amaç: Agent döngüsünün çağıracağı deterministik, saf (I/O yapmayan) bir karar kütüphanesi. Geçen sefer vakit engine *tasarımında* gitti; bu yüzden ÖNCE spesifikasyon, SONRA test, SONRA kod.
- Okunacaklar: `AGENTS.md`, `contracts/config.example.json`, `contracts/decision.md`, `contracts/state.example.json` (metrics bölümü).

## Kapsam (bu kadar, fazlası yok)
1. `validate_config(cfg)` → geçersizse anlaşılır hata mesajı listesi (hangi alan, neden).
2. Getiri serisinden korelasyon matrisi ve ortalama korelasyon ρ̄ (Ledoit–Wolf shrinkage opsiyonel, numpy ile).
3. Holy Grail: `sr_portfolio(sr_i, n, rho) = sr_i / sqrt(1/n + (1-1/n)*rho)` ve `n_eff(n, rho) = 1 / (1/n + (1-1/n)*rho)`.
4. HRP ağırlıkları (scipy hiyerarşik kümeleme).
5. Volatilite hedefleme ile ağırlık ölçekleme + config'teki `max_position_pct` ve `risk_budget_pct` sınırları.
6. `decide(market_snapshot, positions, cfg)` → `contracts/decision.md`'deki karar listesi (BUY/SELL/HOLD, coin başına).
   **Yön sinyali = hedef ağırlığa yeniden dengeleme** (sözleşme değişikliği yok, mevcut config alanları yeter):
   a. Trend filtresi (time-series momentum): `r_i = close_son / close_(son-lookback_bars) - 1`. `r_i <= 0` → hedef ağırlık 0 (nakit).
   b. Trendi pozitif coinler arasında HRP ağırlıkları (tek coin kalırsa ağırlık 1; hiç kalmazsa hepsi 0).
   c. Volatilite hedefi: `w *= min(1, target_vol_pct / portföy_vol_pct)`; her `w_i <= max_position_pct`.
   d. `hedef_usdt_i = w_i * min(equity_usdt, max_total_deploy_usdt)`; `fark = hedef - mevcut_değer`.
   e. `|fark| < min_order_usdt` → HOLD. Aksi halde fark>0 BUY, fark<0 SELL; `size_usdt = min(|fark|, max_order_usdt)`.
   f. `reason` alanı kısa ve sayısal: ör. `"trend +3.1%, hrp 0.42, vol 18%→hedef 20%, n_eff 1.4"`.
   Veri yetersiz / NaN / sıfır volatilite (std=0) / tek fiyat → o coin için HOLD + reason'da sebep; istisna fırlatma.
7. PSR (Probabilistic Sharpe) fonksiyonu — sadece metrik olarak state'e; karar kapısı değil (vakit kalırsa).

## Önce yazılacak golden testler
- sr_portfolio(0.5, 10, 0.6) = 0.625; n_eff(10, 0.6) = 1.5625
- sr_portfolio(0.5, 10, 0.0) ≈ 1.5811; n_eff(10, 0.0) = 10
- sr_portfolio(0.5, 1, x) = 0.5 (her x için)
- Tamamen aynı iki seri → korelasyon 1; HRP ağırlıkları toplamı 1, hepsi ≥ 0
- Geçersiz config (ör. boş coin listesi, max_position_pct > 100) → hata listesi boş değil
- Aynı girdi iki kez → aynı karar (determinizm)
- Bütün coinlerde trend negatif, pozisyon yok → hepsi HOLD; pozisyon varsa SELL
- Sabit fiyat serisi (std=0) ve NaN içeren seri → çökme yok, ilgili coin HOLD
- Hedef farkı `min_order_usdt` altında → HOLD; fark `max_order_usdt` üstünde → `size_usdt == max_order_usdt`
