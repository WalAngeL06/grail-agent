## Kapsam (`chain/` altında, Hardhat)
1. Temel: https://github.com/ava-labs/8004-boilerplate — `.git` olmadan `chain/` içine kopyala (submodule değil).
   Sadece `contracts/` (IdentityRegistry, ReputationRegistry, ValidationRegistry; TaskAgent referans), `hardhat.config.js`,

2. `GrailLedger.sol` ekle:
   - Kurulumda IdentityRegistry adresini alır; sadece kayıtlı agent'ın sahibi/operatörü commit/reveal yapabilir.
   - `commitDecision(uint256 agentId, uint256 cycleId, bytes32 commitHash)` → event `DecisionCommitted(agentId, cycleId, commitHash, block.timestamp)`.
   - `revealDecision(uint256 agentId, uint256 cycleId, bytes payload, bytes32 salt, string okxOrderId)`:
     `keccak256(abi.encodePacked(payload, salt)) == commitHash` değilse revert. okxOrderId hash'e girmez.
     Event `DecisionRevealed(agentId, cycleId, payload, okxOrderId)`.
   - Aynı (agentId, cycleId) için ikinci commit/reveal revert. Commit edilmemiş reveal revert.
   - Sayaçlar: agent başına commit ve reveal sayısı (açıkta kalan = fark) — UI gösterecek.
3. Deploy script: registry'ler + GrailLedger Fuji'ye; agent'ı IdentityRegistry'ye kaydet (ad: config'teki `agent_name`, açıklama:
   "GRAIL: correlation-aware trading agent, OKX ATK demo, commit-reveal ledger"). Ortaya çıkan `agentId`'yi kaydet.
4. Tek `.env` vardır: ana klasördeki `C:\Users\Serdar Arif\Desktop\Agentic Hack\.env` (worktree'lerde kopya yok).
   Hardhat config dotenv'i bu yoldan yükler (`GRAIL_ENV` ortam değişkeni varsa onu kullanır).
